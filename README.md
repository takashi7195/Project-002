# AI3連単

ボートレースの3連単予想ゲームです。

## 履歴と運用ルール
- このプロジェクトの変更履歴は HISTORY.md に詳細に記録する。
- 次の作業者が引き継げるよう、変更内容・理由・日付・影響範囲を残す。
- 日付は YYYY-MM-DD HH:MM 形式で記載する。
- HISTORY.md は追記専用とし、過去の記述の修正・削除・書き換えは原則禁止とする。
- もし記録に誤りがあっても、誤記の訂正ではなく、新しい日付で追記して補足する。
- これは履歴の正確性を保ち、作業の経緯を後から追跡できるようにするためである。
- main は安定版、develop は開発版として扱う。
- 重要な節目では、安定版として保存した状態を明示して記録する。

## 遊び方
1. ボートレース場を選択する
2. STARTボタンを押す
3. ルーレットが回り、3着→2着→1着の順に結果が決定される

## データについて
- データ出典: 艇国DB
- 集計期間: 2025年8月1日～2026年7月31日
- このゲームにおける「コース＝艇番」はゲーム上の簡易モデルであり、実際のレース予想を保証するものではありません。
